# Project Rivet

Unity 6.3 LTS / C# prototype workspace.

**Status:** Initial Unity project and engineering setup.

## Development

Open the project with Unity Hub (Unity **6.3 LTS**, Universal 3D) at `~/Documents/project-rivet`.
Use `bash scripts/publish_public_repo.sh` on the Mac to create a **public** GitHub repository using the existing local Unity project.

This repository begins as a generic public engineering workspace. Product plans and business notes are deliberately maintained **locally and outside Git tracking** while the concept is under development.

Third-party source code and assets must be checked for licensing compatibility before inclusion.
